# Phonema Lab

Laboratorio web de exploración visual de **Visual Phonema** dentro del ecosistema SpukLab / Spoonexx.

## Propósito

Phonema Lab existe para acelerar el ciclo creativo:

**construcción → publicación → observación móvil → feedback → nueva exploración**.

No es el motor final ni una galería de versiones “mejores”. Cada archivo de `explorations/` es una hipótesis visual preservada para comparar direcciones, conservar accidentes útiles y reconocer lenguaje propio.

## Regla de preservación

- Una exploración publicada no se sobrescribe para convertirla en otra.
- Los cambios sustanciales crean un nuevo número.
- Los accidentes interesantes se preservan aunque una exploración posterior tome otra dirección.
- GitHub/Pages es infraestructura; la prioridad es el resultado perceptual.

## Exploraciones

- `001-luminous-colony.html` — primera colonia lumínica autónoma.
- `002-excitation-release.html` — ampliación del contraste entre latencia y exaltación: acumulación, eyección, corrientes, destellos y reagrupamiento.

## Tecnología

HTML/CSS/JavaScript estático. Sin framework, npm ni build system. Mobile-first para Safari iPad/iPhone y Chrome desktop.

## Publicación

GitHub Pages desde `main` / root.
